## Next SEKAI LevelData => [Open Sekai](https://github.com/gaven1880/OpenSekai) Score JSON

This converter does not support:
- Dynamic stages
- Fake notes
- Damage notes
- Custom SFX

Guide notes are only supported in Green and Yellow; other guide colors are converted to Green.

### Usage:
Drag and drop LevelData (JSON and GZip both supported) onto the EXE after building, or run `Lvd2Opsk.exe <path to LevelData>`.
